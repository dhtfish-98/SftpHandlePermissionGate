# Version 0.1.1

This release updates the version and validation metadata. The independent SFTP v3 loopback service, strict reader/editor account grants, per-handle mode checks, live revocation, file-identity checks, limited path allowlist, and decision audit are unchanged from v0.1.0. The test-only weak baseline stays outside the installed wheel.

The v0.1.1 commit and annotated tag use the repository owner's verified GitHub commit address so GitHub links their authorship to `dhtfish-98`. The v0.1.0 release is kept as a historical artifact; its commit and tag metadata are not retroactively changed. Paramiko's LGPL-2.1 license and the Apache MINA SSHD reference remain attributed to their respective owners.

Release evidence must name the exact Git commit, tag, source archive and wheel SHA-256, installed test result, GitHub Actions run, and downloaded asset digest. Local verification alone is `PASS_LOCAL_ONLY`; publication, real-world authorization evidence, and CVP outcome remain separate gates.
